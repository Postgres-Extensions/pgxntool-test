# Every make variable pgxntool's own *.mk files define, with its class.
# test/standard/make-variables.bats fails on any variable missing from this
# list (or listed but no longer defined), so adding a variable to pgxntool
# means deciding here which class it belongs to.
#
# Classes:
#   api       PGXNTOOL_*  -- user-facing override point; document it in
#                           README.asc and treat changes as API changes.
#   internal  _PGXNTOOL_* (or _pgxntool_* for functions) -- plumbing,
#                           including test stub seams. Every new internal
#                           variable must use this shape.
#   legacy    Pre-convention names. Frozen: consumers may reference them, so
#             they are not renamed, and nothing new may be added here.
#   external  Names owned by PGXS or GNU make that pgxntool assigns.
#
# Format: "<class> <name>", one per line, sorted by name. Lines starting
# with # and blank lines are ignored.
